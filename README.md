# 🎮 2DFighters

2DFighters は、HTML5 + JavaScript で制作した **2D格闘ゲーム** です。  
シンプルな操作でスピーディなバトルが楽しめる、ブラウザで動作する軽量ゲームです。

---

## 🌟 特徴

- HTML5 Canvas を使用した軽快な描画
- キーボード操作による直感的なアクション
- シンプルながら奥深いコンボシステム
- 森の中で戦うステージ演出（ウィスピーウッズ風背景）
- 落ち葉エフェクトによる臨場感あるビジュアル

---

## 🕹️ 操作方法

| 指 | キー | 説明 |
|:--:|:--:|:--|
| 人差し指 | **K** | 攻撃 |
| 中指 | **O** | ジャンプ |
| 薬指 | **P** | ガード |

> 💡 キーボードを斜めに構えて、右手の指を K・O・P に置くと操作しやすいです。

## 🧩 技術構成

- HTML5 / CSS3 / JavaScript

---

## 🧠 開発メモ

- 背景の森は `drawBackground()` 関数で描画
- 落ち葉エフェクトは `Leaf` クラスで制御
- 操作説明図は `assets/images/controls.png` に配置
